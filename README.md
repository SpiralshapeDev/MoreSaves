# More Saves

[Apache License, Version 2.0]: https://github.com/SpiralShapeDev/MoreSaves/blob/master/LICENSE-APACHE
[Bepinex pack for Undermine]: https://www.nexusmods.com/undermine/mods/5

This mod expands the save functionality in Undermine, allowing you to create multiple saves beyond the original three. The default number of pages in the mod's config is 99 pages, this can be increased infinitely.

## License
More Saves Mod is released under the [Apache License, Version 2.0].

### Requirements
- [Bepinex pack for Undermine]

## Installing
1. Install [BepInEx][Bepinex pack for Undermine]
2. Download and extract the mod.
3. Copy the mod's folder to your "<Undermine-Steam-Files>/BepInEx/plugins" directory.
4. Run the game.  Enjoy!

## Usage
Modify the entries automatically generated in your BepInEx configuration file path, usually located at [ ./BepInEx/config/SpiralMods.MoreSaves.cfg ].
If you cannot see this file, try running the game with the mod so that the file can be generated by BepInEx, if that doesn't work, verify if you have the mod correctly installed.

## Building
1. Copy files from `<Undermine-Steam-Files>/BepInEx/core` to `.libs`
   1. `0Harmony.dll`
   2. `BepInEx.dll`
   3. `BepInEx.Harmony.dll`


2. Copy files from `<Undermine-Steam-Files>/UnderMine_Data/Managed` to `.libs`
   1. `Rewired_Core.dll`
   2. `UnderMine.dll`
   3. `UnityEngine.CoreModule.dll`
   4. `UnityEngine.dll`
   5. `UnityEngine.ImageConversionModule.dll`
   6. `UnityEngine.TextCoreModule.dll`
   7. `UnityEngine.TextRenderingModule.dll`
   8. `UnityEngine.UI.dll`
   9. `UnityEngine.UIModule.dll`
   10. `Unity.TextMeshPro.dll`


3. Build solution


4. Built mod should be located at `bin/Debug/MoreSaves.dll`
